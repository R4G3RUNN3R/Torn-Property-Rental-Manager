# Torn Property Rental Manager

A standalone Torn.com userscript by R4G3RUNN3R for scanning owned properties, comparing the current rental market through the Torn API, recommending competitive lease pricing, and preparing the native Torn lease form for manual submission.

## Safety boundary

The script may automatically perform Torn API reads and local calculations. It does **not** automatically submit property rental actions, issue background non-API Torn requests, bypass CAPTCHA, or programmatically click native action controls.
